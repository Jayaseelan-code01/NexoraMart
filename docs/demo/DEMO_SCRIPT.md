# 7-Minute NexoraMart Demo Script

## 1. Opening
Introduce NexoraMart as a smart campus marketplace built on JDK 17, Tomcat 9, Maven, H2 and JSP/JSTL.

## 2. Buyer Journey
Register/login → browse catalog → live search → Visual Search → open product details → compare → wishlist → add to cart → checkout → order history → review.

## 3. Smart Features
Demonstrate Smart Match with a purpose, budget and priority. Then ask the Nexora AI Assistant for a product recommendation.

## 4. Seller Journey
Open Seller Pro Dashboard → show inventory health, products and orders → demonstrate an order status update.

## 5. Admin Journey
Open Admin Control Center → analytics → moderation → audit log.

## 6. Closing
Show Color Theme switching and responsive/mobile layout. Mention testing, CI, security hardening and required diagrams in the repository.
