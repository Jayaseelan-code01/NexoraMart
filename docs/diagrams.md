# Required Diagrams

The capstone requires three diagrams based on the actual implementation:

1. ER Diagram — users, products, orders, order_items, cart_items, reviews and related relationships.
2. Use Case Diagram — Buyer, Seller and Admin actors with the implemented F1–F8 use cases.
3. Sequence Diagram — place-order flow: Browser → Servlet → Service → DAO → Database → response.

Create the final visual versions from the current schema and code before submission.
